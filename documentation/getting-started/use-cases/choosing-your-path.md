# Choosing Your Path with sprint-mcp

Welcome to sprint-mcp! This guide helps you find the right starting point for your needs.

## What is sprint-mcp?

**sprint-mcp** is a structured workflow tool for organizing any creative or technical work with Claude. Whether you're planning a YouTube series, building software, or exploring new ideas—sprint-mcp keeps everything organized.

**Key insight**: sprint-mcp works with Claude (your AI assistant) to help you complete projects, not just start them.

## Understanding the Spectrum

sprint-mcp supports a wide range of work styles. Here's how to think about it:

### Planned ↔ Exploratory ("Vibe Mode")

```
PLANNED SPRINT              STRUCTURE THE VIBE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Clear goal                  "See what happens"
Defined deliverables        Emergent outcomes
Execute the plan            Capture discovery
Professional rigor          Creative freedom
```

**Both are valid!** Use what fits your project.

---

### Non-Coding ↔ Software Projects

```
NON-CODING PROJECTS         SOFTWARE PROJECTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Content creation            App development
Planning & strategy         Tool building
Creative work               Automation
Learn sprint methodology    Apply sprint methodology
(Familiar domain)           (New domain for non-devs)
```

**Recommendation for non-developers**: Start with a non-coding project to learn the process, then transition to software when ready.

## Common Questions

### "Is this too technical for me?"

**No!** You don't need any technical knowledge to use sprint-mcp. If you can work with Claude, you can use sprint-mcp.

- **Non-developers**: Start with a non-coding project in a domain you already understand
- **Developers**: Jump right in with a software project

### "Do I need to know git?"

**For non-developers**: No. Claude handles the technical setup for you.

**For developers**: Basic git knowledge helps, but Claude guides you through sprint-specific workflows.

### "What if I don't have a clear plan?"

**Perfect!** That's what "Structure the Vibe" mode is for. You don't need a detailed plan to start. sprint-mcp helps you organize your exploration so nothing gets lost.

### "Can I use this for non-software projects?"

**Absolutely!** sprint-mcp was designed for *any* structured work:
- Content creation
- Event planning
- Product launches
- Creative projects
- Client work
- And yes, software development too

## Quick Decision Guide

**Answer these questions**:

1. **Are you comfortable with command-line tools?**
   - Yes → Developer path
   - No → Choose your role (Creator, Maker, Hobbyist, Freelancer, Writer)

2. **Is this a software project?**
   - Yes, I'm a developer → Developer Quickstart
   - Yes, but I'm not a developer → Learn with non-coding project first
   - No → Perfect! Start with a non-coding project

3. **Do you have a clear plan?**
   - Yes → Planned Sprint
   - No, I'm exploring → Vibe Mode
   - Not sure → Start with Vibe Mode (less pressure)
